# Firma logoları

Bu klasöre iki logo dosyası ekleyin (sürükle-bırak yeterli):

| Tema | Dosya adları (öncelik sırası) |
|------|-------------------------------|
| Açık | `logo-light.svg` → `logo-light.png` → `logo-light.webp` |
| Koyu | `logo-dark.svg` → `logo-dark.png` → `logo-dark.webp` |

Örnek:

```text
public/brand/logo-light.png
public/brand/logo-dark.png
```

Dosya yoksa sol üstte logo alanı boş kalır. Tema değişince ilgili logo otomatik seçilir.
